# «يومك» — دليل الأماكن ونقاط التفاعل (Hotspots) — النسخة 2
> يكتبه السيناريست، ويلتزم به وكلاء المشاهد الستة. معرّفات `hotspot` ومواقعها **لم تتغير**. معرّفات `npc` تغيّرت (انظر القسم التالي) وهي مطابقة لملفات `content/script/*.json`.
> الوحدة = متر. الأرضية y=0. **+x يمين، +z نحو الكاميرا/اللاعب عند البداية**. الإحداثيات تقريبية (±1م مسموح) مع الحفاظ على الترتيب والعلاقات.
> هندسة إجرائية فقط (صناديق، أسطوانات، مستويات). الأسلوب: **low-poly دافئ** بألوان مسطحة ناعمة، بلا نصوص داخل المشهد إلا عبر `makeLabel`.
