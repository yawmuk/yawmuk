## How to verify — كيف تتحقق بنفسك

1. **Run the audit:** `npm run audit` (= `node tools/audit/verify.mjs && node tools/audit/links.mjs`). It needs network access the first time (downloads are cached in `tools/audit/.cache/`; add `--no-cache` to re-fetch). Exit code 0 means every check passed.
2. **Qur'an** — every ayah is re-fetched from the King Fahd Glorious Qur'an Printing Complex via [quranenc.com](https://quranenc.com) (`/api/v1/translation/aya/english_saheeh/{sura}/{aya}`). The Arabic must equal the Madinah-Mushaf text **exactly**; the English must equal the Complex-reviewed Saheeh International translation (footnote markers removed); every letter is also cross-checked against Tanzil. Click any Qur'an link below to read the ayah on quranenc.com.
3. **Hadith** — only hadith graded صحيح or حسن by an approved source are shown to players. Six-book texts are matched letter-by-letter (with harakat) against the sunnah.com text (hadith-api). For every hadith outside al-Bukhari/Muslim the record names the dorar.net entry (المحدث | المصدر | الرقم | خلاصة حكم المحدث) and links to it — open the dorar link to see the grade exactly as dorar shows it; where a HadeethEnc.com entry exists its grade is re-fetched by the audit. dorar.net and sunnah.com block automated clients, so those links are checked structurally and must be opened by a human.
4. **Madhhab / contemporary** — open the link or the cited volume/page. These are **not** machine-verifiable and stay `pending_human` unless the auditor read the page directly.
5. **What the status means:** `machine_verified` = the text (and, for hadith, the grade record) was matched against the source by `verify.mjs` or read directly by the auditor; `pending_human` = not matched, a person must check it; `reviewed` = a human scholar signed off (**none yet**). It does **not** mean a scholar reviewed the ruling.

«موثّق آلياً» يعني أن النص طوبق آلياً (أو يدوياً) مع مصدره حرفاً بحرف، ولا يعني أن عالماً راجع الحكم؛ لم تُراجَع الأحكام بعدُ من عالم بشري. شغّل `npm run audit` لإعادة التحقق، وافتح أي رابط أدناه للاطلاع على المصدر.
