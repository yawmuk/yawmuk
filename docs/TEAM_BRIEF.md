## الوثيقة المرجعية لفريق الوكلاء (Contracts) — يملكها الوكيل المشرف

> ## ⚠️ تحديث 2026-10-05 — تغيير جوهري في الفكرة (يتقدم على كل ما يخالفه أدناه)
> بقرار صاحب المشروع: **آدم شاب بالغ غير مسلم** يعيش في Columbus, Ohio، وهو **مهتم بالتعرف على الإسلام** (تحديث 2026-10-06: لا يُسمّى أي دين آخر في القصة أو الأحكام أو الواجهة). اللعبة تعرّفه بالإسلام من خلال مواقف يومه مع **أصدقاء وزملاء وجيران مسلمين**، وأهمهم **مرشد مسلم** (صديقه عمر) وإمام المسجد (الإمام حمزة).
> 1. **دور آدم**: متعلّم يرى كيف يتعامل المسلمون حوله مع المواقف (قرض البيت، الطعام، الحفلات، اللقطة…) ويختار ماذا يسأل وكيف يتصرف. معنى `quality` في الخيارات صار: `best` = تصرف/سؤال محترم وفضولي يقود إلى فهم صحيح لموقف الإسلام؛ `acceptable` = مقبول لكنه ناقص؛ `wrong` = افتراض خاطئ أو صورة نمطية أو تصرف يحرج صديقه المسلم أو يسيء فهم الإسلام. الحكم الشرعي يبقى في بطاقة الحكم كما هو، ويُعرض بصيغة «ماذا يقول الإسلام ولماذا».
> 2. **المعرّفات ثابتة**: الـ18 `ruling_id`، ومعرّفات الأماكن، ومعرّفات الـhotspot، وقيم النقاط 10/5/0 و+5 لسؤال الفهم — لا تتغير.
> 3. **حقول جديدة في كل حكم** (`content/rulings/*.json`):
>    - `newcomer_explainer`: `{ "ar": "", "en": "" }` — شرح مبسط (3–5 جمل) لغير المسلم: ما الحكم ولماذا (الحكمة/المقصد كما ذكرها العلماء، بلا مبالغة ولا جدل).
>    - (أُلغي حقل `common_ground` بقرار صاحب المشروع 2026-10-06؛ لا يُعرض ولا يُكتب.)
>    - **حقول الحزمة العلمية (2026-10-06)** — مستويات المحتوى وضبط الاستجابة:
>      - `content_level`: `"A" | "B" | "C" | "D"` — أ: معلومة أصلية مستقرة (إجابة مباشرة موثقة)؛ ب: شرح واستدلال (من المادة المعتمدة مع المرجع، بلا قطع فيما يحتمل الخلاف)؛ ج: مسألة خلافية أو حساسة (إجابة مقيدة وبيان الخلاف أو الإحالة)؛ د: فتوى أو حالة شخصية (لا حكم — معلومات عامة وإحالة).
>      - في المستوى ج يكون `verdict` إما `disputed` أو `depends`، أو يُضاف `verdict_scope` `{ar,en}` يبيّن أن الحكم المعروض قول الجمهور أو يحدد صورته.
>      - `explanatory_notes`: `{ "ar": [], "en": [] }` — استنتاجاتنا وقياساتنا التوضيحية، تُعرض تحت «شرح توضيحي — ليس نصاً شرعياً».
>      - `consensus_sources`: `["مرجع + جزء/صفحة أو رابط"]` — إلزامي إن ورد في أي نص معروض لفظ إجماع/اتفاق/consensus.
>      - `madhahib.<m>.reference_status`: `"pending_verification"` حين لم يُتحقق من المرجع؛ تعرض البطاقة شارة «المرجع قيد التحقق» ولا يُكتب في `reference` أي تحفظ ذاتي.
>    - **⛔ قرار صاحب المشروع (2026-10-06): لا يحتوي المشروع أي نص أو إحالة من الكتاب المقدس/التوراة/الإنجيل** — لا اقتباسات، ولا أسماء أسفار، ولا أرقام إصحاحات/آيات. يحرسه `tools/audit/scripture_guard.cjs` واختبارات الأمان.
> 4. **النهاية**: ملخص ما تعلمه آدم + موضوع تالٍ مقترح + إحالة إلى مسجد محلي أو مركز تعريف بالإسلام. **لا ضغط، ولا قياس للمعتقد، ولا تخزين لأي معلومة عن معتقد اللاعب.**
> 5. **النبرة**: احترام كامل للاعب وخلفيته، بلا انتقاص ولا مقارنة تفضيلية بين الأديان ولا مناظرة. الإسلام يُعرض بوضوح وثقة ودفء.
> 6. **الشخصيات**: آدم وأسرته بلا رموز دينية معيّنة، والمسلمون هم: عمر (المرشد الرئيسي)، زملاء/جيران مسلمون، يوسف ومريم (العرس)، الإمام حمزة. التفاصيل في `docs/story_bible.md` بعد تحديثه.

> كل وكيل يقرأ هذا الملف كاملاً قبل البدء. لا يعدّل أي وكيل هذا الملف؛ أي اقتراح تغيير يُكتب في تقريره النهائي للمشرف.

### الفكرة
لعبة ويب ثلاثية الأبعاد (Three.js، تعمل في المتصفح على الحاسوب والهاتف) تتابع يوماً عادياً لـ **«آدم»**، شاب مسلم (28 سنة، مهندس برمجيات مبتدئ ويكمل دراسة مسائية في كلية مجتمع) يعيش في مدينة أمريكية متوسطة (Columbus, Ohio) وسط مجتمع غالبه غير مسلم. يمرّ اللاعب بست محطات، وفي كل محطة مواقف يختار فيها تصرفاً، ثم تظهر **بطاقة حكم** موثقة بالقرآن والحديث والمذاهب الأربعة والمجامع الفقهية المعاصرة.

مبادئ إلزامية (من وثيقة التحدي):
1. **الفصل بين القصة والمعلومة الدينية**: الحوار تخييلي، أما الحكم والدليل فيأتيان حصراً من ملفات `content/rulings/`.
2. **لا اختلاق**: لا يُكتب نص آية أو حديث إلا منقولاً حرفياً من مصدر موثوق مع الرقم ورابط المصدر ودرجة الحديث. إن لم يُتحقق من نص يُترك الحقل فارغاً ويُذكر ذلك في `notes_for_reviewer`.
3. **عرض الخلاف بأمانة**: المذاهب الأربعة بأقوالها المعتمدة، مع الإشارة إلى المرجع (كتاب معتمد في المذهب أو موسوعة فقهية).
4. **الإحالة**: كل حكم يعتمد على تفاصيل شخصية يتضمن متى يجب سؤال مختص.
5. واجهة **عربية (RTL) وإنجليزية**.

### عقد المشهد — `src/scenes/<location>.js`
```js
// هندسة إجرائية فقط (Three.js primitives) — بلا ملفات نماذج خارجية.
export default {
  id: 'home',
  title: { ar: 'المنزل', en: 'Home' },
  build(ctx) {             // ctx = { THREE, mats, makeNPC, makeLabel } يوفرها المحرك (انظر src/engine/README.md)
    return {
      group,                // THREE.Group — الأرضية عند y=0، وحدة القياس = متر
      spawn: { position: [x, 0, z], yaw: 0 },
      colliders: [{ min: [x,y,z], max: [x,y,z] }],    // صناديق تصادم AABB
      hotspots: [{ id: 'laptop', position: [x,y,z], radius: 1.5, label: {ar:'', en:''} }],
      npcs: [{ id: 'sara', position: [x,0,z], yaw: 0, look: { skin:'#c68642', shirt:'#3a6ea5', hijab: true } }],
      exit: { position: [x,0,z], radius: 1.5 },          // باب الانتقال للمحطة التالية
      lights: 'day | evening | night',
      update(dt, t) {}, dispose() {}
    };
  }
};
```
